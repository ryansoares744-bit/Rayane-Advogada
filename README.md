# Rayane Braga Advocacia — Landing Page

Site estático (HTML). Não precisa de build.

## Estrutura
- `index.html` — a página
- `support.js` — runtime da página (necessário, manter na mesma pasta)
- `assets/` — foto, posts do Instagram e avatares dos depoimentos

## Como subir no GitHub
1. Crie um repositório novo (ex.: `rayane-braga-lp`).
2. Envie **todo o conteúdo desta pasta** (index.html, support.js e a pasta assets) para a raiz do repositório.

## Como hospedar na Vercel
1. Acesse vercel.com e clique em **Add New → Project**.
2. Importe o repositório do GitHub.
3. Em **Framework Preset** escolha **Other** (é um site estático).
4. Deixe os campos de build vazios e clique em **Deploy**.
5. Pronto — a Vercel publica o `index.html` automaticamente.
